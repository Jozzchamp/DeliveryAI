# 🚚 DeliveryAI – Food Delivery ETA & Delay Prediction

An AI-powered food delivery analytics platform that predicts estimated delivery time and identifies potential delivery delays using Machine Learning.

## 🎯 Project Overview

DeliveryAI uses machine learning algorithms to analyse food delivery data and predict delivery time based on factors such as distance, traffic, weather, preparation time and courier experience.

## ✨ Key Features

- Food Delivery ETA Prediction
- Delivery Delay Prediction
- Interactive Analytics Dashboard
- Data Visualization
- Machine Learning Model Evaluation
- SHAP-based Feature Importance Analysis

## 🛠️ Technologies Used
